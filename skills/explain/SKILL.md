# Explain

Explain the thing the user points at so a beginner can follow it.

1. Read the code, file, or error first.
2. Start with one sentence: what it does, or what went wrong.
3. Walk through the important parts in order. Use short sentences.
4. When you use a technical word, say what it means the first time.
5. End with one small thing the user can try to check their understanding.

Do not change any files. This skill only explains.
