# My rules for Claude

Claude reads this file at the start of every session.
Keep each rule short. Add your own rules at the bottom.

## How to work

- Explain what you plan to do before you change any file.
- Make small changes, one step at a time.
- After a change, tell me how to check that it works.
- If something is unclear, ask me instead of guessing.

## Safety

- Ask me before you delete any file.
- Never put passwords, API keys, or tokens in code.
- Never push to git unless I ask.

## How to talk to me

- Use simple words and short sentences.
- If I ask a question, answer it first. Then add details if needed.
